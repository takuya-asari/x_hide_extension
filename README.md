# switch X

「Switch X」は、Xの画面に表示されるさまざまなものを、ボタンひとつで手軽に非表示にできる拡張機能です。

<img width="1089" height="804" alt="image" src="https://github.com/user-attachments/assets/cc6f7054-9941-4d0b-82c7-9f1164c2e315" />

Firefox addonストア
https://addons.mozilla.org/addon/switch-x/


## 【こんな方におすすめです】
・タイムラインの閲覧に集中したい方
・サイドバーのニュースやおすすめユーザーをすっきり隠したい方
・自分好みのシンプルな画面でXを使いたい方

## 【できること】
ポップアップのスイッチを切り替えるだけで、以下の要素を個別にオン／オフできます。

・サイドバーの各種ブロック（プレミアム案内、トレンドニュース、「いま」を見つけよう、おすすめユーザーなど）
・タイムライン上の広告表示

## 【使い方】
1. 拡張機能をインストールして、X（旧Twitter）を開きます。
2. ブラウザ右上の「Switch X」アイコンをクリックします。
3. 隠したい項目のスイッチをオンにするだけで、すぐに画面に反映されます！

※本拡張機能は個人が開発した非公式の拡張機能です。X Corp.とは一切関係ありません。

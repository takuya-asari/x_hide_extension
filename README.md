# switch X

switch XはX（旧ツイッター）のPCブラウザ版で使えるchrome拡張機能です。

### サイドバー

- プレミアムにサブスクライブ
- 本日のニュース
- 「いま」を見つけよう
- おすすめユーザー

### タイムライン

- 広告ツイート

を簡単にボタン一つで非表示にすることができます。

---

Xはひんぱんに仕様が変わります。

不具合はご連絡ください。
